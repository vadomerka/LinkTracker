# LinkTracker

LinkTracker – Telegram-бот, который отслеживает изменения на веб-страницах и оперативно информирует пользователя о них.

Технологический стек проекта: Java Spring, Docker, PostgreSql, Apache Kafka.

Проект состоит из 3 модулей и одной библиотеки

bot
- интерфейс проекта, отвечает на сообщения пользователей, делает запросы к scrapper 
scrapper
- бизнес логика проекта, сервис отвечает за хранение, обновление и возврат информации о ссылках. 
ai-agent
- сокращает информацию об обновлениях на сайте, используется скраппером
global-models
- связующая библиотека в которой находятся классы, используемые в нескольких модулях проекта.


Актуальная версия проекта находится в ветке /dev - v0.1
